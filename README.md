# Track 1 Working Repository (co-leads)

The group-facing Track 1 documents have moved to the task force repository: [ayraforum/gdc-trust-registries-tf](https://github.com/ayraforum/gdc-trust-registries-tf) — start with the [Track 1 README](https://github.com/ayraforum/gdc-trust-registries-tf/blob/main/README-Track1.md).

This repository remains the co-leads' working space for material that is not part of the group deliverable:

- [diags](diags/README.md) — PlantUML/C4 diagrams of the trust pattern (driver's license, national ID, passport, web of registries).
- [Later Phases](later-phases/README.md) — broader issues deliberately kept out of the initial framework, including verifier, relying-party, reader, and wallet governance questions. Deliberately rougher than the main framework.
- [references-and-inputs](references-and-inputs/README.md) — source material consulted while preparing the drafts. Internal preparation context; not group material.

Working notes prepared for Track 1 discussion:

- [Two Ideas for Track 1: Focused Ecosystems and Assurance Levels](track1-share-focus-and-assurance.md)
- [The Unfunded Obligation: A Design Risk for Track 1](track1-unfunded-obligation-risk.md) — why "where is the global registry of registries, and how is it funded?" has a trap in it, and what to write into the framework instead.
- [Discovery, And How Global Registries Get Established](track1-discovery-and-global-registries.md) — for the October 2026 monthly meeting: discovery is a different question from recognition, discovery should not require anyone to watch it, and what establishing a global registry actually costs.
