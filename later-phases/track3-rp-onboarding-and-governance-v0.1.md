# Superseded: Track 3 RP Onboarding and Governance Framework v0.1

This draft has been superseded by [Track 3 Issuer Onboarding & Governance Framework v0.1](../track3-issuer-onboarding-and-governance-v0.1.md).

The earlier RP/verifier framing was useful because it exposed downstream wallet-side checks, verifier access, and presentation-scope issues. However, the Track 3 centerline has been reframed as issuer onboarding and governance: how issuers enter an issuer trust registry, how they remain in good standing, and how verifiers and wallets check whether a credential or claim comes from an authorized issuer.

For verifier-side consumption of issuer trust, see [Government-Issued Identity RP Profile Draft](government-issued-identity-rp-profile-draft.md). Treat that file as a supporting strawman, not the main Track 3 deliverable.
