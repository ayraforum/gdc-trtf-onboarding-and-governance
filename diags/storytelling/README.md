# Storytelling Graphics

These graphics are more presentation-oriented than the PlantUML system diagrams in the parent folder. Use the PNGs for web pages, slides, and quick sharing; edit the SVGs when the content or layout needs to change.

| Graphic | Web PNG | Editable SVG | Shows |
|---------|---------|--------------|-------|
| Trust pattern, plain language | [PNG](00-trust-pattern-plain-language.png) | [SVG](00-trust-pattern-plain-language.svg) | A non-technical version of the generic trust pattern: authority, issuer, person, verifier, trust registry, and trust decision. |
| Two-sided trust story | [PNG](01-two-sided-trust-story.png) | [SVG](01-two-sided-trust-story.svg) | The two-sided pattern: an authority exposes trust information; a verifier asks a trust registry for usable answers; the verifier keeps the trust decision. |
| Question pattern flow | [PNG](02-question-pattern-flow.png) | [SVG](02-question-pattern-flow.svg) | The repeated question pattern: credential type, issuer, authority basis, registry lookup, registry answer, and verifier trust decision. |

The PNGs are exported for high-density web and slide use. The plain-language trust pattern uses a wider 4000 x 1700 export; the other two are 3200 x 1800.
